文組都會的 Angular 教學(1)

讓我們從安裝說起。

Ossian Lin Published on Oct 2019

前言

「你是不是瞧不起文組，在那邊戰文理組！」

呃，我也是菜鳥初學者。

雖然本身也是理工背景但只會寫 Matlab，基於工作需求開始學習寫網頁前端。_(:з」∠)_

網路上一定有許多神人教學文章，但資質駑鈍的我有看也不一定懂。所以就嘗試把自己摸索的過程以圖文並茂的方式盡可能寫成文章。

喔，對了，這系列不太會寫什麼複雜的內容，我只打算按部就班以最簡單的方式寫成。另外有很多可能會比較主觀，若有建議歡迎賜正。

檔案下載

撇除電腦網路不說，你只需要下載兩樣東西：

  • Node.js
  • 編輯器

Node.js

進去官方網站，挑一個你喜歡的版本下載，然後按部就班安裝就對了。

「不是，有兩個版本，還有一堆英文，差別在哪啊？」

呃，好喔，稍微解釋一下。

LTS 是大多數人都在使用的版本；Current 則是目前最新的版本。

個人是不強求一定要挑哪個版本啦，反正我是挑 LTS 就是了。

下載完檔案後，點兩下左鍵開始安裝 Node.js。第一頁沒啥重點，就是 Next 下一步就對了。

第二頁是要你同意一些條款，記得把 “I accept the terms in the License Agreement” 前面的方框打勾，然後Next往下。

第三頁是詢問你要安裝在哪個地方，通常會預設在電腦本體系統相關程式的硬碟，這邊因為個人有專門丟程式的硬碟所以有些不同。也沒甚麼特別的地方，直接Next往下。

接下來這頁可能會讓人感到驚慌，但不用擔心，主要是讓人客製化安裝的。一樣不用想太多，Next直接往下。

這邊是問你要不要順便裝其他可能需要用到的工具，原先預設是沒打勾的，我個人剛好有需要所以勾選；如果沒特別需求，記得不要打勾，確定後再點Next往下。

一切就緒，就點下Install正式安裝吧。

好了，其實你已成功安裝完 1/2 的 Angular 了，接下來你需要一個可以撰寫的地方。

編輯器

編輯器有很多選擇，例如較有名的 Notepad++、或是網頁的 Stackblitz, Codepen, Augury，甚至打開內建的文字編輯器也是可以。如果沒想法不如跟我一樣看到最多人推薦的就挑來用吧！微軟推出的 Visual Studio Code 是近期比較多人推薦使用的，介面上也頗簡潔；另外，也有許多擴充功能來讓使用者更客製化。

下載完成後，一樣點開直接安裝。VS code 安裝是繁體中文介面，所以這邊講解上比較沒甚麼需要解釋的會走快一點。一開始需要接受合約才能往下一步前進，都要安裝了當然是接受咯！

接下來是選擇要安裝的地方，我這邊一樣是放入寫程式用的路徑。一樣沒特別需求的人直接用官方預設好的，點下一步往下。

接下來這邊就是個問你從"開始"這邊點開要去哪裡找到 VS code，一樣用預設好的就可以了，直接下一步。

這邊比較特別的是否要執行額外的工作，官方預設「加入 PATH 中」是打勾的，不太需要動到甚麼就直接下一步準備開始安裝。

好的，最後要正式安裝前做個確認，沒問題就直接安裝吧。

安裝完打開後可能會有許多人又感到焦慮，整個介面滿滿的英文，連選單內容都是，然後不敢亂點的情況下不知所措，甚至心想：「诶诶诶，這不是大廠微軟嗎？繁體中文介面呢？」

沒事，這感覺我懂。我還是在選單中找了一下語言設定的，大概 5 分鐘。

然後我就問了 Google 大神。

Google 大神很慷慨地給了專業解答，就是 VS code 他老爸—微軟。

「 自己去找吧，我把全 VS code 的擴充功能都放在那裡了。」

嗯，點了上面連結的同學進去一定在想：「說好的繁體中文介面呢？」

呃，如果你是趕時間的請往這邊，下載並安裝就完成繁體中文化了；不趕時間的容我稍作解釋。

簡單來說，就是 VS code 的某些功能是要靠擴充功能來更改，而第一個連結導入到的是擴充功能主頁面，你可以想成是個大賣場；從 VS code 程式內點也可以進行擴充功能的安裝，比較像網路購物。

「好的，我點了，然後呢？」

我有嘗試過直接搜尋"中文"但沒有理想答案，不過單純輸入 “Chinese” 是可以的，為了精準一點這邊示範輸入 “Traditional Chinese” 並劃上重點讓各位清楚點。

大致上 Visual Studio Code 的安裝教學就到這邊，大致都完成了。

開始安裝

好的，接下來打開命令提示字元(cmd)安裝剩下 1/2 的 Angular 吧！

“OK，Google. How to open cmd?”

打開命令提示字元的方法有很多種，可以問 Google 大神，這邊就只教兩種方法。

第一種方法就是看看你電腦左下角"開始"旁邊是否有個"搜尋"的按鈕，有的話點下去然後輸入cmd就看的到了。

沒有的同學也別緊張，另外一個慢慢找的方法就是點開開始→所有應用程式→找到Windows 系統資料夾→點進去就有了。

「诶诶诶，這是甚麼？這裡是哪裡？我是誰？」

冷靜，接下來要安裝了，跟著步驟走保證沒問題。(大概啦)

不過在開始之前，先回頭檢查個東西，就是 Node.js。檢查方式很簡單，就是輸入下面這段文字然後看有沒有跑出版本號這樣。

node -v

另外確認是否有安裝到 NPM 的方法就是輸入：

npm -v

好的，如果確認沒問題後，就往下吧！首先，把這段文字複製貼上，或是手動打上去，然後按下鍵盤上的Enter他就開始跑了。

npm install -g @angular/cli

跑完後他會問你是否要匿名分享資料給 Angular 團隊並附上聲明，這邊就看個人決定吧！公司用的電腦是選擇Yes，家用電腦我則是選擇No。

然後先稍微檢查一下是否安裝成功，在下面輸入這段文字：

ng version

然後就會出現如下圖所示，這樣就是完成 Angular 安裝了。

後記

好的，你已經會安裝 Angular 了，接下來就可以開始寫網頁前端了。

有些文章都會介紹建置一份網頁做為測試，不過我覺得留到下一次再說，畢竟開一份新網頁的步驟也差不多，所以這邊就先不做教學。

希望這圖文並茂的文章能讓你感到手把手般、有安心踏實的教學。

如果有任何疑問或是建議都歡迎賜正。
