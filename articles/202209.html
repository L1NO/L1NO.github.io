三周年紀念🎉

設計鳥生活滿三歲啦！

Ossian Lin Published on Sep 2022

前言

又到了每年九月這日子唯一會準時的一篇，過去一年依然每個月一篇的堅持下來到了第三年。隨著對疫情的改觀，各式活動也慢慢恢復實體，讓大家再次回到線下實體活動互相碰面認識新朋友；除了參與活動，平時的閱讀當然也沒少過。

今天這篇不意外的除了慶祝滿三年外，主要還是會聊過去一年撰寫文章的歷程，以及第四年的新展望。廢話不多說，讓我們開始吧！

回首檢視

開場一樣先來回首檢視過去一年發生的事情，什麼？你說期許？好像去年就沒預期這回事了，畢竟達成率極低不如我們...反倒維持「良好的」每月出產一篇文章才是最重要的呢！

而過去兩年默默的努力其實也不是沒有幫助，對於在社群活動上認識新朋友還是面試時的履歷資料，都有發揮不錯的加分效果。不論是否從事設計的朋友，都很推薦用寫文章方式來當作學習歷程記錄，當然也可選用其他例如拍 Youtube、寫 Instagram、錄製 Podcast 等方式來呈現。

二周年後發生的事

在二周年過後就開始尋找新的 UX 研究員職缺，主要目標當時是希望能練一些研究員技能及實戰，也因此都放眼研究員職缺及投遞，同時也分享了第一份工作經驗，帶各位認識一下法人單位在南部大概做些甚麼內容，以及一些內幕(？)；殊不知又碰巧得拿到另一間法人單位的 offer，展開新的早起通勤且充實的研究員生活。

由於台灣設計研究院不同於資策會以技術為主，這邊多數以研究為出發，可說是一切開端前的準備，為了就是讓後續能有個明確的方向順利進行；因此產品的開發暫時不是當前會碰到的部分，把讀完的產品路線圖做為暫時的最後分享。而因為疫情的關係轉為線上的 IxDA Taiwan 互動年會，也在年末時舉辦了最後的收場活動，當然也寫了年末最後一篇的總整理文章作為 2021 收尾。

隨著農曆新年的結束，迎來期盼許久的實體互動聚會。這次帶來的是不需要程式技巧就能上手的跨螢幕互動遊戲創作工作坊，不但吸引了設計師同好外，也有不少工程師前來參與，一同窺探如何能不用懂任何 code 狀況下就達到跨螢幕的技術。另外四月場的 Design System 也讓大家一探設計系統該如何建立、運用，來建立起與工程師等其他同事溝通的橋樑。

線上活動則有六月場由寶博士帶來的 Web 3 及 Metaverse 的介紹，帶領大家從網站初期形式如何演變到熱潮 Web 3，區塊鏈在這之中扮演著甚麼樣的角色，以及如何發展向看似科幻的 Metaverse，藉由這場講座就能一次瞭解。

除了實體及線上聚會外，自身的精進也是不可少。三月的時候分享了新手在設計及開發產品的一些經驗談，用過往自己實作過的產品帶大家了解產品大概是怎麼樣的流程。另外其實在三月底的同時也離開了第二份工作台灣設計研究院，決定想往產品設計師的方向，也分享這短短幾個月的工作經驗。另外在準備及修改履歷的同時，也受 Ian 推薦閱讀蕭瑞麟老師的《思考的脈絡：創新，可能不擴散》，瞭解如何有效地去撰寫個案的脈絡。

新展望與挑戰

So…截至今日至少已經 5 個月仍在尋找新工作，雖然這中間也面試過不少間各領域的 UI/UX 職缺，不過多數也都感謝函或是無聲卡居多。整體面試遇到的狀況大概也寫了一篇簡單的分享，等之後有新 offer 後會再寫一篇各領域面試的細節。

誠如前面提到持續至今第三年，在這段面試中都有被正向肯定，雖然沒有到很熱門或是很有名氣，但至少在履歷上多了一點不錯的成果作為呈現。因此會很建議不論是甚麼職位領域，都應該試著紀錄自己的學習歷程，畢竟這就像是作品集一樣，總能展現自己的成果。

當然除了眼前需要繼續尋找合適工作外，也開始放眼更後續的事情，比較像是面試常問的「未來 3 年、5 年，甚至 10 年規劃」。其實不敢保證能繼續待在設計圈有點小成就，因此也是要開始思考再更之後的規劃。不過看了台灣醫工相關工作的薪資福利，或許短期內還是不會回頭吃這老本行吧！

後記

嘛，人生第二次的裸辭其實還是沒有感到太可怕，反倒在這趟求職馬拉松上學到不少東西。相信不少人會聽過「求職是一場長程馬拉松」，確實也是如此，如果有短期內想馬上找到的那就會是短期衝刺賽，但多數還是以長程賽為主，唯一要謹記的是不能停下腳步選擇放棄。

其實這段時間除了改履歷、投面試外，也藉由面試各領域來了解到不同產業需要 UX 設計師這職位來協助公司達到甚麼目標。有些是為了協助轉型，有些則是正在起步需要一個調節人員等，各式需求都有，當然也不依訂每個職位需求實際都向工作敘述所需的一樣；正因如此，面試上更該多問多了解自己未來接應該職位，會遇到的相關狀況。

最後，原定三周年打算出一套 LINE 貼圖之類的，不過很不巧的前前東家發現居然忘了收走我的 Adobe 權限緊急回收，加上還未決定是否引入電繪版重新畫製，因此應該是會拖到五周年再發布吧(？)。關於這部分也還在考量中，詳細就有待之後文章看有沒有發布相關資訊吧！

以上，我們下次見，啾~
