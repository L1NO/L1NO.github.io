文組都會的 Angular 教學(2)

讓我們來建立一份新網頁吧！

Ossian Lin Published on Nov 2019

前言

好的，上一篇教了各位如何安裝 Angular，但最後有提到少了一步普遍教學文章會提的—建置一份新網頁作測試，所以這次的教學主要就是提這部分，也會稍微介紹一些介面上的檔案。

網路上一定有許多神人教學文章，但資質駑鈍的我有看也不一定懂。所以就嘗試把自己摸索的過程以圖文並茂的方式盡可能寫成文章。

喔，對了，這系列不太會寫什麼複雜的內容，我只打算按部就班以最簡單的方式寫成。另外有很多可能會比較主觀，若有建議歡迎賜正。

事前工作

OK，在正式建置之前，我們先來挑要建立的路徑位置，就是你要把東西存在哪裡這樣，任君挑選、沒有限制。

接下來要用命令提示字元(cmd)來切換路徑。

怎麼打開 cmd 請回上一篇有教學，這邊直接簡單說切換路徑這件事。

cmd 中切換路徑的指令為cd，接著把複製的資料夾路徑貼上、然後按下Enter即可，實際大概會像這樣：

cd <資料夾路徑> (記得要跟cd空一格)

這邊再教一個打開 cmd 的方法，同時也可以直接做完切換路徑。

首先到選定的資料夾內，點選上方路徑，然後滑鼠左鍵點下去輸入cmd再按下 Enter就會自動打開並切換好路徑的命令提示字元(cmd)了。

建置新網頁

OK，這樣總算能開始建置了。

首先輸入專案名稱，指令如下：

ng new <你想要的專案名稱>

輸入完後按下Enter就會跳出下一步，這邊問的是：「是否要加入 Angular 路由？」本次 demo 建置我們先選擇不要，因此輸入N(大小寫皆可)並按下Enter進入下一步。

OK，最後一步會問說想要的 stylesheet 格式。

這邊有五種選擇給你挑，基本上本質都是 CSS (就是管理你版面顏色、位置等)，在這邊我們挑選 CSS 最基本的開局就好。

使用鍵盤上的方向鍵來挑選，然後按下Enter就會自動開始建置了。

接下來系統會自動跑一堆東西就稍微眼睛放鬆一下，等全部跑完後會再次跳出可輸入的狀態，基本上這樣就建置完成了。

如果你害怕的話，可以點開存放專案的資料夾確認，基本上會有一個稍早輸入專案名稱的資料夾出現，然後裡面有不少檔案。

那至於如何開啟網頁呢？一樣先回到 cmd 來輸入指令，然後按下Enter：

ng serve

「诶诶，怎麼出現紅紅的字，是不是壞了！？」

沒錯，因為沒切換到專案路徑內，因此無法開啟專案的網頁；所以必須先切換路徑後，再輸入開啟網頁的指令。

切換路徑的方法同本章前面教學，其實原本的 cmd 視窗是已經可以關閉的了，不過這邊為了一次教到底所以直接繼續下去。

確定切換路徑後，也輸入完指令並按下，系統就會自動跑一下，然後產生一個網址：http://localhost:4200/

直接打開隨意一個瀏覽器(就是你的 Google Chrome 啦)，然後手動輸入，或是滑鼠反白後ctrl+c, ctrl+v貼上後Enter 就會跳到一個預設網頁。

在這網頁內的東西都是 Angular 預設建好的，我們只要確認 Title 的地方是否為專案名稱即可，其他按鈕連結都會導入至 Angular 相關網站。

恩，這樣就大功告成了。

從 VS code 開啟

好的，可以先把瀏覽器關了。

接下來還有另外一件事—「如何從 VS code 開啟專案」

前一篇有提過 VS code 會用來之後的網頁編輯，這時候我們就要使用 VS code 來開啟專案，同時試著重新叫出剛剛的網頁。

這邊教兩種開啟 VS code 的方式：

  • 從 cmd 下指令開啟。
  • 從 VS code 開啟。

從 cmd 下指令開啟

這個比較簡單，確認好 cmd 是否為專案路徑後，輸入code .然後按下 Enter就會自動開啟 VS code，而且是直接到專案資料夾。

從 VS code 開啟

既然是從 VS code 手動開啟，那當然要先開 VS code 咯~

開啟之後每個人畫面可能稍微有點不同，畢竟有可能已經有個人化設定過，不過別擔心，這都不是重點。

我們要開啟的目標是「專案的『資料夾』」，因此只要找到選擇開啟資料夾的選項，並找到專案資料夾，給他開啟下去就對了。

選擇資料夾要記得找到「專案資料夾內」再做選擇。

選擇確認後就會開啟資料夾，基本上如下圖所示就是完成了。

為了確認是真的開起專案資料夾，同時也操作一次用 VS code 開啟剛剛的預設網頁，接下來直接輸入ctrl+`來開啟終端機。

一樣輸入稍早教的指令ng serve然後Enter按下去跑一下，一樣會產出一段跟之前在 cmd 產出的網址，這邊方便一點是可以對網址ctrl+滑鼠，就可以開啟網站了。

以上就是基本的 VS code 開啟資料夾教學。

後記

原本考慮直接講解一些小東西，例如：檔案介紹、替換 html 內容、實際 ts 簡易操作，但發現一來講太多東西會造成閱讀壓力、二來我也懶了，乾脆丟到下一篇慢慢講，因此這次就先到這邊。

希望這圖文並茂的文章能讓你感到手把手般、有安心踏實的教學。
