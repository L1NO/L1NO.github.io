初出茅廬的設計指南

《UX 策略：設計讓人夢寐以求的創新數位產品》讀後心得

Ossian Lin Published on Feb 2021

前言

時間拉回 2020 年 11 月左右，當時正在規劃「如何寫出自己風格」的作品集而不斷尋找有相關背景的請教，其中很榮幸與 Josh 一場會面後，他提供了兩本不錯的書籍讓我閱讀，也希望藉此找到方向。

Hmm…當然，通常推薦我書籍一定是當下就去買，但何時能看完就不這麼肯定了。¯\_(ツ)_/¯

於是時間一拉長就來到 2021 年過年期間才正式閱讀完畢，雖然說這樣延長了一大段時間，不過中間是持續閱讀所以不少內容也就能實際應用上。沒錯，這本書是能夠現學現賣的！

So..UX 策略又是甚麼新名詞嗎？

根據作者解釋為：一個在設計或開發數位產品前就要先開展的過程。不同於 UX 設計著重於細節上，UX 策略是一整個系列的核心策略—像是上層的計畫，用來在各種不確定的狀況下達成商業目標。

軟體工程師的團隊發現他們花了幾百萬得到的不是成果，而是一個沒有吸引任何客戶的產品。

既然稱作策略，其概念上就是提出計畫、發覺自己的優劣勢，靠著實證等方式推往理想的成果。而文中有提到要注意的四項常見誤解，分別是：當成「北極星」(或說是明燈)、「有策略地」執行 UX 設計、UX 策略就是產品策略、和品牌策略完全相關。

傳統公司常會有設定一個目標就開始展開一連串執行，某些專案確實是可以這樣搞，但如果今天是要弄數位產品(尤其常聽到的「要創新」)，那就要靠 UX 策略的快速迭代等敏捷手法。前面提到 UX 是一個大方向，因此實際上跟 UX 設計專注於特定工作上較為不同。

與產品策略最明顯的不同之處在於：UX 策略通常會連結橫跨數個不同得產品，或像是 Adobe 串接自家底下的 Photoshop、Illustrator 等。那是否與品牌策略完全相關？相較之下比較像是兩者相輔，好的品牌策略能訂定品牌訊息、傳達內容等，但今天 UX 策略做得也很好大眾仍然會先焦點於「品牌」上。例如微軟推過的 Windows phone 應該就是不錯的例子了，大家對於微軟已經有不錯的品牌印象，便很自然地認為 Windows phone 應該也不會差到哪裡，而最後微軟收掉了這分項。

那麼，要如何做策略呢？

在開始正式詳細介紹設計策略前，本書有列出四大信條作為依據：商業策略、價值創新、實證使用者研究、殺手級 UX 設計。其中作者將這些列成一條自己的方程式：

UX 策略 = 商業策略+價值創新+實證使用者研究+殺手級 UX 設計

藉由這四個信條在後面每個階段都會有所對應，有效的讓讀者知道該階段立基於哪些信條之上。接下來會大略帶過各章節內容，同時也是一套策略的誕生。

在專案一開始通常大家都是急忙定義產品願景，但實際上應該是先找出目標族群及使用者痛點，因此驗證價值主張是 UX 策略的第一步，在這邊會著重於商業策略跟價值創新；接下來會是基於商業策略的競品研究與其分析，藉由研究市面上各產品是如何滿足目標族群的需求、同時知道有哪些「直接競爭對手」、「間接競爭對手」及「UX 影響者」，誰成功、誰失敗都是商業策略的關鍵資料。而這些研究資料也能深入了解目前趨勢，以及汰換過時的心智模型(Mental models)。接著競品分析將大問題拆解成小問題，挑出對團隊有利的部分、給出建議替代方案，甚至深入一點可能還能從中提別具一格的解法。

有了研究結果，接著找出關鍵經驗、利用 UX 影響者，再來就是基於價值創新跟殺手級 UX 設計的用故事板思考價值創新，就是利用熟知的故事板以視覺方式述說你家產品/服務關鍵經驗的故事；以上這些前置作業後，接著就可以開發原型，進行實驗，這裡是將這四個信條實際應用，盡快且頻繁地獲得顧客的回顧以確認是否偏離目標，即熟悉的最小可行性產品(MVP)；在實際操作實驗時可以利用一種稱為游擊式使用者研究，利用小型結構式質化實驗來加速實證使用者研究成果，立即從使用者身上得到驗證；最後也是四個信條實際應用的提升轉換率的設計，利用漏斗矩陣的工具，藉由定義出可量測指標來做為衡量不同顧客的共同依據，進一步設計提升顧客參與度的深度。

延伸閱讀：《觀察顧客階段的小工具 — 顧客體驗路徑×漏斗矩陣》(Medium)

後記

本書中個人很喜歡在章節開始前都會舉一個實例，不論這個實例是好是壞，最重要是讓讀者有個情境能對接下來要說明的內容有些假想，同時在實例介紹完會有個經驗分享的小節錄，幫讀者劃重點。

藉由書中每個章節按部就班的操作，確實對我在整理作品集上有不少幫助，而對於工作上在做 survey 這類事項上也能交出更有架構、甚至對於提案內容「有效修改」的成果，當然上司買不買單這我就不知道了~

作者有不斷提到另一本《精實創業：用小實驗玩出大事業》(博客來)，我也在快讀完前已先行購入，至於甚麼時候讀完...恩，個人是當成延伸閱讀(或說 DLC？)，既然都被多次提及相信也是值得去看。

以上，我們下次見，啾~
