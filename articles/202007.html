Akane 老師的 UX 研究方法實戰班

2020 年 7 月台北場次的個人課後心得

Ossian Lin Published on Jul 2020

前言

2020 年真的是個各種展會、聚會活動取消一年，不過很幸運的 Akane 老師的課程有開成，而且同年 8 月也繼續開了 UI 課程班，雖然很想接續著上課但礙於工作問題還是放棄再衝一波了。

相信不少人應該都很熟悉 Akane 老師所寫的 Blog—嫁給 RD 的 UI Designer，而老師過去也都有開班授課。在過去一年多的時間除了閱讀老師的文章外，中南部場次的演講也都盡可能參加聆聽，除此之外，對於 UX 的相關知識平時也是自己看看文章、書籍等慢慢摸索；因此當看到老師這次開課即便在台北，覺得還是要去上課比較能了解整個 UX 工作的內容、同時藉著這個機會去實際操作。

然後我就很迅速地按下了報名。(一秒)

課程內容

課程一開始主要內容是基本知識為主，如果你沒有概念除了好書閱讀外，也可以看我之前寫的簡易懶人包喔！不過其實這些你在開始報名前老師就有交代要先看完了，這邊不到 10 分鐘左右就結束。緊接著就正式進入了 UX 設計師的專業領域，所以沒有先備知識的接下來真的就會有聽沒有懂，或者朦朧懂。

專業技能的部分有像是目標為「探索現有狀況、理解使用者如何執行具體任務，並分析其行為的依據和目的」的任務分析(Task Analysis)、收集「了解目標族群在工作實務上描述」的脈絡訪查(Contextual Inquiry)，以及「將研究的觀察結果和發現具體呈現並做有意義分類、成為設計依據」的親和圖(Affinity Diagram)等。除了這三項外，常聽到的人物誌(Persona)、使用者旅程圖(User Journey Maps)、使用者故事(User Story)等都沒有少，而且通通都有讓學生們實作。

三天的課程中也有些比較輕鬆的知識，像是關於開發流程的介紹、UX 設計研究基本流程，或是思辨的檢查，主要就是讓我們對於使用者的語句進行真實性的分析，究竟使用者說的是絕對真實、無法爭論的「事實」，還是需要討論、釐清的「觀察」，抑或是自己遇見的人事物而成的「經驗」。

還有一些關於測試上的小技巧，或是測試任務目標的設定，以及對使用者進行訪談時的方向和注意事項等內容。這種都是比相較專業技能來說比較輕鬆易懂的。

課程最後老師也快速帶大家做了一次狩野分析(上個月剛好複習完)，不過時間上的限制加上老師的用途有些不同，因此這邊其實趕很快；尾聲的部分則講解了一些像是在公司導入 UX 設計的觀點，以及一些在做 UX 上的注意事項，就這樣結束了三堂週日的實戰班課程。

課後心得

三堂課程的內容真的很多，也不至於到難，真的難的部分在於到職場上的實際應用，或是帶入工作環境應用。課程中有幾項比較印象深刻的，像是老師有提到產品團隊的 2 個重點 — 「探索」與「交付」(又或是指「開發」，以下會用「開發」來解說比較好理解)，其兩者的解釋為：

  1. 探索：是指對於未開發前的種種未知，而進行風險評估、判斷創意想法的好壞。
  2. 開發：打造、提供產品或服務至市場上進行銷售等。

其實常理來說一個 case 都應該該分成這兩個重點，但在我的工作環境是沒這麼做到明顯，甚至根本也沒有著重。至於外界公司如何，我就不清楚了。然後就會要我們拿著 MVP (Minimum viable product，最小可行產品)去找客戶測試、得到回饋，且要找客戶買單，總覺得哪邊怪怪的~

另外，課程中老師有提到 Jesse James Garrett 的使用者經驗分層元素。相信多數人應該都不太熟他是誰，但如果是寫網頁相關的或聽過「AJAX」這個名詞的時候應該就能吸引到你的注意，嘿丟，「AJAX」這個技術就是他命名的。(維基百科)

從圖中可以明顯看出分成 5 層，這邊就不多做翻譯解釋。根據右邊箭頭由下往上是指「從概念到成品」、左邊則是「抽象到具體」，而這 5 層其實也有人整理對應至人機互動。

延伸閱讀 — Human-Centered Interaction Methods vs Elements of User Experience. (Medium)

實戰的部分除了有機會能實作，也趁著機會找出自己的弱項。像個人就覺得「脈絡訪查」是有待加強的。

雖然說對於初學者做使用者訪談這件事是真的難了許多，畢竟第一次又要在有限時間內問陌生人一連串問題，除了考驗臨場反應外，別忘了動手記錄使用者所說的語句、情感表情上的改變等。一邊聆聽抄寫對我個人來說不算困難，但要問問題這就卡著了，畢竟不是單純的閒聊，加上問話上有許多要注意的眉角，否則會得不到想要知道的、還會讓話題過度發散；不過跟我對練的夥伴剛好反過來，她個人表示自己會記得要問問題，而會忘記要抄寫下來。嘛，這部份真的只能多練習了，當然也不是說練就有得練。

課程中也有不斷的練習親合圖、使用者故事等，在這樣親自操作、與組員討論下比較能感覺到身為一位 UX 設計師要做的有哪些工作，以及如何對公司有「產出」。談到產出成果這件事情，我也是在這課程中知道如何去呈現，畢竟是有研究性質，自然要有個報告之類的，但如何撰寫呈現在之前的學習或是工作上都很難去達成。

總結

雖然課程分成 3 個週日，這樣南北來回燒高鐵票算是頗貴，但也總算是比較踏實些，知道自己過去摸索的時間沒有浪費、方向也是正確的。尤其更能知道在未來的工作上該精進哪些部分，以及自己的弱項還有待努力。

如果對於 UX 設計工作內容有興趣的，我個人很推薦去上這實戰班，畢竟可以完整的了解工作內容，同時跑過一輪工作上可能會運用到的情況，而且也不會艱澀難懂。當然，還是要具有先備知識才去上課，否則基本上是無法跟上的。

台北場緊接著 8 月有開 UI 課程班、9 月也在台中有開，但礙於工作加上經濟能力這兩場次只好先行放棄，還是在許願池有留言希望能開南部場，如果開台南場次我也是能衝啦...

以上，我們下次見，啾~
