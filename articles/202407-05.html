📝Soking 老師週報心得(2024/07/08)

本週主題：運用 Side project 走出認知的荒野

Ossian Lin Published on Jul 2024

前言

2024 年 7 月第二週週報，午後雷陣雨的夏天...

Soking 老師說這週原本要寫的內容因為太過魔幻，因此臨時更換成關於「side project」的主題。本週內容主要是因為老師近期要準備辦一場直播講座，將邀請串門子社會設計來分享如何用設計改變社會，計會分享到關於 side project 從落地到執行這方面的內容預。在活動籌備過程期間需要先調查看看大家的想法，老師也因此藉機分享自身看法讓各位能發掘自己理想的 side project！

接下來就跟著 Soking 老師本週週報，一起發掘理想的 side project 吧！

從串聯中找到 side project 的意義

Side project 這件事情對於許多人應該不陌生，尤其是喜歡探究嘗試新事物、下班後仍有熱情可以繼續燃燒的讀者，應該都會有 1~2 個 side project 在手上。我個人也是如此，包含每週寫著 Soking 老師週報心得也是一項 side project。每個人對於 side project 的期望不同，有些人是想增加作品、有些人為了提升能力，不過多數人還是因為做 side project 能讓自己感到更快樂、有成就感而願意持續做下去。以個人來說就比較屬於提升能力這件事情上，畢竟每週 Soking 老師丟出不一樣的內容，要在短時間內理解轉化並以文字呈現，是個挑戰也是個讓我樂於其中的一件事。

Soking 老師提到關於自己發起某項屬於自己的 side project 時，通常開始當下都沒甚麼起色、甚至感到沒用，當未來與某件事情串連起來時，當時感到沒用的 side project 卻在某個案件中扮演重要的角色、發揮應有的效益。這種事情對於普遍讀者來說都是會遇到的，就像我持續經營這個 Medium 許久可能會有人提出「都沒起色」之類的疑問，雖說本來就沒有特別想要營利，但那些日積月累、現在回頭看那些非常可觀的文章數量，加上每週隨機短時間的理解，我發現在工作上遇到需要理解上司含糊的夢想時，可以如何迅速的推演出一個情境，並試著以較簡明的方式讓其他位理解的同事跟上腳步。從這樣的例子可以得知即便我們熱衷的 side project 當下無法馬上看到實質效益，但在未來某個時間點串聯起來時所帶來的幫助才是真正的意義。

在荒野中尋找真實的寶藏

在上一段我們知道了 side project 是藉由與其他事情串連而被發現意義的，那麼這段過程要持續多久才可能促成讓我們遇見想要的 side project？Soking 老師分享到自己都是透過記錄、分類等方式去將嘗試過的不可行保存下來，每次 side project 開頭都像是身處荒野，我們必須自行為「認知」進行拓荒。用個簡單例子，例如被上司交辦舉辦一場聚餐，如果這場聚餐主題是類似同學會性質，我們可能沒主辦過但至少有參加過，在認知能掌握的範圍下可以有概念的準備這場聚餐。如果是偏向國際友邦參訪般莊重，此時我們毫無認知下只能尋求其他支援、甚至花錢請專業人士主辦。

既然在這片認知荒野上探索自然少不了重要的「地圖」，因此 Soking 老師分享在這過程中第一類寶藏是「地圖」，指的是對於這片荒野的脈絡理解清楚程度，就像前面的例子當聚會是像國際等級般莊重，我們對於活動的脈絡就非常模糊，請來專業的活動主辦方因為已經有專業及經驗，自然可以拿出一份合宜的地圖，我們藉由與他人學習、慢慢比對摹寫，最後不但可以有一張在這片荒野使用的地圖，甚至是比這些專業活動主辦更廣大的地圖。第二類寶藏 Soking 老師稱為是「新物種」，可能是對我們或他人帶來益處的、也可能是寶箱怪帶來危機，不論是正反哪個對於我們在這場探索中都是有幫助的。最後一種收穫是「關係」，探索過程中可能會遇到願意交換資源、給予並建立彼此信任，或是單純帶來衝突等各種樣式的人，我們都會建立起關係，對於後續交手上讓彼此更能理解如何應對。

從上面介紹了三種常見的寶藏後，可以發現其實不論在這場拓荒中收穫哪個還是全都包辦，這些益處中就是回歸到我們身上，讓我們在這場探索中有所成長，而我們要做的事就只有勇於起身前往探索。

後記

本週 Soking 老師分享我們應該如何面對 side project，許多人會因為初期沒有起色的回饋感到失望，然而當未來與某個事件串連起來時，回頭去看才會發現原來當時有這樣的經驗，讓這次的事件如此應手般的呈現意義。探索認知荒野是一場充滿挑戰但又充滿收穫的冒險。在這個過程中，我們可以收穫知識、技能、經驗和人脈等不同資源，從而實現個人成長。因此 Soking 老師也鼓勵各位勇於探索認知荒野，收穫屬於自己的寶藏。

最後，別忘了 Soking 老師預計在 8/15(四)晚上有場直播講座，邀請豐富經驗的社會企業「串門子」來分享他們帶著探索的故事。幫忙老師填寫事前調查問卷不但能幫助講者調整當天分享內容，也能有機會抽到直播票，有興趣的讀者現在就馬上填寫問卷！

Take away:
1. Side project的意義是藉由許多事件的串連而成的，很少單一事件就能完全展現。
2. 探索認知荒野是一場充滿挑戰但又充滿收穫的冒險，勇於探索認知荒野，收穫屬於自己的寶藏。

以上，我們下週見，啾~
