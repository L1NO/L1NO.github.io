📝Soking 老師週報心得(2023/03/06)

本週主題：像個 UX 設計師思考，讓選擇更容易。

Ossian Lin Published on Mar 2023

前言

2023 年 3 月第一週週報，居然三月了！？

每項職業都有獨特的技能，而發揮這項技能除了更穩定角色定位外，還能跟自己的工作更有共鳴。本週 Soking 老師將帶領大家探索 UX 設計師的特色，如何幫助使用者能有更好的體驗、同時也為商業層面帶來更多的利益。

接下來就跟著 Soking 老師本週週報，瞭解如何善用 UX 設計師的能力吧~

UX 設計師的被動技能

遊戲中常會有所謂的被動技能(Passive ability)，就是專屬某個角色或是職位的非主動能力，例如 MMO 的防禦職業會有較高的防禦力、輔助職業有較佳的恢復等。在現實生活也是如此，產品經理可能有較佳的時程控管概念、視覺設計有直覺性的美感等，那我們 UX 設計師呢？

Soking 老師以最近在規劃一場給各行各業工作者們的工作坊為例，老師在籌備上遇到要如何以基本道理講解課程的窘境，「怎麼樣的產品設計思考方式，才像是 UX 設計師呢？」，最後以 UX 設計師身分回顧思考得出了我們的被動技能—「讓選擇更容易」。

UX 設計師這份專業的重點，在於如何設計產品服務的體驗過程，消除那些對於使用者覺得麻煩、看不懂、害怕犯錯的選擇設計，移除這些障礙之後，整理出一條明確的理想路徑，讓使用者搭上直達車，一眼就可以看見最終目的。

人們都有選擇困難的時候，尤其當選擇越多時會讓人花更多時間去選擇，導致無法繼續完成任務，另外人的大腦是相當懶惰的器官，對於重複性高的任務我們會選擇最節省心力的選項，而導致「我全都要」以及「我只想要」這些情況，當我們能將這些選擇簡易化讓人們更容易選擇時，其實正是在做體驗流程的改善。

我們用個簡單的舉例：每日早晨購買咖啡可能就因時間、路線等多種因素導致選擇多樣(e.g. 超商、咖啡店、個人沖泡)，如果加以分析我們可能就會縮減得到剩下幾個選項(e.g. 超商A每周一都固定特價、對於咖啡店A已有品牌忠誠)，這些選項中除了個人選擇能更容易直達理想目標外，同時對商業上也帶來許多價值。

更簡易的選擇、更多樣的益處

初學 UX 時爬了很多書籍文章，當下只覺得「哇 UX 什麼都要會」。從心理學、人文學等以前很少接觸的學科都會觸及，往產品面走還有工程學、程式語言等要學習，在使用者研究上更有一堆技巧(e.g. 質性/量化研究)等著去練。過了一段時間跟工作歷練，其實回頭看這些也不會是全部都要熟練，同時也理解到我們在設計上不僅是美觀漂亮的成果，核心是找出使用者在接觸產品服務過程中的狀況。根據 Soking 老師整理常見探討的問題如下：

  1. 你的產品服務所提供的新事物，有吻合使用者腦袋中想要的用途嗎？
  2. 你所期望的行為，使用者會知道要在什麼情況下做嗎？
  3. 你要求使用者付出的行動，對使用者當下的情境來說，合理嗎？
  4. 你的產品服務過程提供的選項，使用者知道該如何選擇嗎？
  5. 使用者可以很輕易的想像使用你的產品服務會發生哪些過程嗎？

如果每對上述一個問題沒有把握，就會連帶提高產品服務的成本，例如行銷推廣、客服處理這些對使用者的面向，而對內部則有費時心力的調整改善、客製化要求等。以上這些問題除了成本的提高，也使得產品服務難以規模化，如同救近火般只是不停的客製化改善、增加技術債。因此「讓選擇更容易」，明確的知道目標族群在什麼情況下會需要你家的產品服務，同時吸引需要這項產品服務的使用者們前來使用。

後記

身為 UX 設計師，因為我們比其他人需要專注於更細微的事情，以研究、實驗等方式去挖掘驗證，讓微小的關鍵點促成一項巨大的轉捩點，帶來更好的流程體驗。

當我們能明確鎖定相似需求的使用者，就能減少多數的不確定性、使用者也能依據提供的引導簡單地完成任務，同時當使用者意識能很輕易的達成目的時，產品服務就自然更容易推廣出去。有了這樣的掌握，對公司內部以少量但有用的服務鎖定目標族群，間接減去無止盡的添加新功能，防患更多需求規格以及技術債等問題。

讓選擇更容易不僅是在做使用者體驗的改善，同時也讓產品服務大幅提昇競爭力，這正是 UX 設計師的被動技能。

Keyword:
1. 人們都有選擇困難，UX 設計師則讓選擇更容易。
2. 人都有惰性，尤其重複性高的工作會下意識選最簡單的。
3. 讓選擇更容易帶來更好的體驗，進而為商業價值帶來好的影響。

以上，我們下週見，啾~
