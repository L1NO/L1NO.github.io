📝Soking 老師週報心得(2024/12/23)

本週主題：UX 新手的自學方針

Ossian Lin Published on Dec 2024

前言

2024 年 12 月第四週週報，聖誕節的一週。

上週 Soking 老師分享了四個面向來幫助各位建立適合自己的 UX 學習地圖，有了地圖之後就要起身而行，否則也只是空想抵達目的之後的事情。因此本周 Soking 老師為各位讀者整理盤點自學的方針，從心態建立到實際教材挑選都有介紹，而本周週報心得也有依循老師分享的書籍提供心得連結幫助讀者們可以更深入的「預覽」書籍。

注意！只是「預覽」而不是懶人包，即便我的心得看完可能讓人感覺不推薦，但每個人讀後心得皆不同，務必自己心中要有一把衡量的尺規來審視是否閱讀被推薦的書籍。

接下來就跟著 Soking 老師本週週報，一起了解如何規劃自己的學習方針吧！

UX 與心理學的關係

相信讀者們在初期學習 UX 時都有過「這是心理學吧！」的感覺，畢竟有許多的知識看上去像是學者們長期研究記錄下得到的結果，讓人誤以為學 UX 還要學會抽象的心理學，當然這也是為什麼有些說法是心理學系畢業會跑來做 UX 設計師。經過一些工作坊或產品開發實作後，仔細觀察會發現其實只是將心理學作為基底轉化應用於商業市場。不論是否學術派出身應該在學 UX 時都多少聽過唐·諾曼(Don Norman)這位發明 UX 這個詞彙的祖師爺，以心理學家的身分推廣「設計避免讓人犯錯」的體驗設計，也就是 UX 設計師們延續至今所信奉的第一原則。

知到 UX 設計師從使用者為出發、理解人類的行為時，我們就能夠讓許多生硬的東西變簡單易懂，這樣的改變下影響最廣泛且最具成果的就是軟體產業。在過去寫部落格幾乎跟使用 Word 寫好後發布沒甚麼太大差異，而到了現在隨意找幾個寫作平台都有著簡單的操作介面，將撰寫需要的字體變換、插入圖片、段落分行等常用功能精簡至文章中且易取得，讓人可以更專心於寫文章這件事情上。市面上五花八門的軟體介面亦是如此，在警示、通知等常用行為在研究後刻意設計讓人能輕鬆完成目的，這些都存在著從使用者身上取得資訊後所帶來的改變。

針對不同的設計，我們應該試著到現場了解使用者當時的情境，從觀察中發現為什麼會產生如此需求；如果無法直接觀察，這時候則有著一系列從旁觀察的方法，或是與團隊及決策者溝通討論後，來幫助我們的設計能落實解決需求。因此在 Soking 老師的整理中有不少建議都是新手可以持續鍛鍊的實作能力，同時每年幾乎也都有開相應的課程，真的自己操作不熟悉很推薦留意一下老師開課資訊，花點時間實作也順便認識新朋友。

學習的最好方式即回歸從閱讀開始

作為一位新手最好的做法就是多閱讀書籍，Soking 老師在週報中推薦不少書值得去翻閱看看，不過盤點後發現只有一篇是我有讀過且撰寫過心得的，因此只特別提這本《我們的行為是怎樣被設計的》(心得連結)。回頭翻了心得發現這篇居然已經是 4 年前的文章，即便今年也將要結束，本書內容仍非常推薦給初次接觸 UX 設計的讀者。在本書中分成兩個部份，首先介紹設計歷史的由來，再介紹近代的設計應用有哪些，對於不論是想回顧設計史或直接學習應用案例的讀者都能快速上手的一本好書。

Soking 老師的書單中雖然有許多我未曾讀過的，但 UX 設計師本來要閱讀的書籍範圍甚廣，即便相同類型的主題每個作者的解讀也會有些許差異，更不用說現代變遷快速可能半年左右就又有新的看法或應用案例。因此除非某本書是非常基礎的，我認為各位都可以依循其他人推薦的書籍後，到實體店面走走翻閱，再決定哪些是自己想看的內容。

規劃屬於自己步調的學習計畫

嗯，UX 接觸領域甚廣，因此很多人會感到焦慮是正常的，包含我也有過。我們通常會隨著不斷的學習精進後，慢慢對某項知識技能有概念而做出選擇，有時候甚至可以判斷是否該捨棄。什麼都想學並不是件壞事，而是沒有方向性的學習才會使我們感到迷惘，因此老師在周報中引用了線上課程專家喊涵用於學習評估的 EPSS 熟練度量表，來作為個人學習某項新之前的自我評估。個人覺得這是一個很直觀、容易理解的評量方式，先讓自己有概念性的盤點當前認知程度，再慢慢找出適合的方式往上學習，同時也能夠評估接收的新資訊是否是需要，好讓自己能更有時間去打理其他知識技能。

​誠如開頭提到 UX 接觸領域甚廣，除了專業技能要培養，也可以從自己本身背景或有熱忱的領域作為起點，了解產業市場的風向已逐漸是設計師的能力，何況我們都會關注新的設計潮流，對於科技、人文等多樣攝取也是能勝任的。例如我較多時間關注遊戲產業，即便我不是身處遊戲產業的設計師，藉由跟同好們的討論、觀察遊戲業發展趨勢等，可以看出 UX 設計在遊戲產業當前定位及風向是什麼，甚至擴展來看軟體業的走向狀況。因此不一定要將自己投入在沒有熱忱的領域，找到適合自己的主題去堆疊知識，才能學習的更有效率。

後記

本週 Soking 老師介紹了學 UX 有哪些技能、可以看哪些書籍，以及如何評估自己當前學習階段來規畫學習目標，這些都是 UX 新手們常提問且感到疑惑的問題。UX 設計的道路充滿挑戰，但也充滿了無限可能，透過理論與實踐的結合，我們能不斷成長而成為一名出色的 UX 設計師。Soking 老師的分享讓我們對 UX 學習上更有踏實感，也激發了我們持續學習的動力。我認為保持開放的心態，不斷學習新知，才能在這個快速變化的產業中保持競爭力。

Take away:
1. UX 設計師的基本功：學會觀察人類。
2. UX 有許多好書值得閱讀看不完？最後還是要回歸選擇自己適合的才是重點。
3. 善用 EPSS 熟練度量表來自我評估當前熟練度，再來有效安排自己的學習計畫。

以上，我們下週見，啾~
